## Project Overview

The **Student Performance Indicator** is a machine learning project designed to predict and analyze student performance. It uses a complete ML pipeline that includes data ingestion, transformation, model training, and prediction capabilities.

> Find the problem statement at [problem statement](./001-problem-definition.md)

### Key Features

- End-to-end ML pipeline implementation
- Exploratory Data Analysis (EDA) via Jupyter notebooks
- Multiple data transformation strategies
- CatBoost model training and evaluation
- Prediction pipeline for inference
- Modular, extensible architecture

## Workflow & Pipeline

Main pipeline uses the CRISP-DM framework for implementaion

📊 CRISP-DM Phases

- Business Understanding → Define objectives, success criteria, and constraints.

- Data Understanding → Collect, explore, and assess data quality.

- Data Preparation → Clean, transform, and structure data for modeling.

- Modeling → Select algorithms, train models, and tune parameters.

- Evaluation → Check if the model meets business goals and metrics.

- Deployment → Put the model into production, monitor, and maintain.
